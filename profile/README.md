# Ainfera

**Agent-native language models, built under evidence.**

Ainfera builds **Neptune** — a clean-lineage program for agent-native models, a Stage-0 trust factory, and verifiable evaluation surfaces.

## What we ship

| Layer | Role |
|-------|------|
| **Neptune Core** | Open proof layer: `Neptune-1.0-27B` and `Neptune-1.0-9B` |
| **Stage-0 factory** | Provenance, admission, training control plane, and release gates |
| **Eval certificates** | Preregistered held-out evidence and **VAC/$** (Verified Agentic Completions per Dollar) |
| **Closed specialists** | Domain systems served privately; not open-weight by default |

## Product principle

Training completion is not a release criterion.

No Neptune model claims superiority, ships publicly, or supports external narrative without:

1. Preregistered, held-out comparative evidence  
2. Provenance-bound reproducibility  
3. A passing release gate
